# Examples

Use this folder for pointers to canonical project patterns.

Prefer short notes over pasted code. A good example entry names the file,
explains why it is canonical, and warns about any traps.

Example:

```md
# API Route Pattern

- Canonical file: `app/routes/widgets.py`
- Use this for request validation, response shape, and error handling.
- Do not copy the legacy auth check from older routes.
```
