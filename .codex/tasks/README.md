# Task Playbooks

Use this folder for repeatable project workflows that are too specific for
general docs and too useful to rediscover.

Good task notes are short and operational:

- When to use the workflow.
- Files or modules to inspect first.
- Commands that verify the change.
- Common failure modes.
- What should not be changed casually.

Suggested task files:

- `interview.md`
- `add-feature.md`
- `debug-production-issue.md`
- `release.md`
- `update-docs.md`
